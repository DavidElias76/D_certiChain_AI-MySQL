L1Controller layer — HTTP boundary

Each controller method validates the request shape, delegates to the auth service, and shapes the HTTP response (JSON body + httpOnly cookie where required).

L3Middleware — request guard

The wall between anonymous and authenticated. Pulls the Bearer token, verifies it, hydrates req.user.

Express middleware

Signature
+  authMiddleware(req, res, next)RequestHandler
Behavior table
StepLogicOn failure
1Read Authorization header401 — "No token provided"
2Split "Bearer {token}" → take token
3jwt.verify(token, ACCESS_TOKEN_SECRET) → cast to DecodedToken401 — "Invalid or expired token"
4Hydrate (req as AuthenticatedRequest).user = { id, username, role }
5Call next()

L4Repository layer — MySQL access

All persistence goes through raw SQL with parameterized placeholders via mysql2. No ORM. Each method returns a typed shape or null.
